# Ramo de flores amarillas 3D 💛

Mini web romántica hecha con HTML, CSS, JavaScript y Three.js.

## Personalizar el mensaje
Edita `index.html` y cambia el texto dentro de:

```html
<p id="message"> ... </p>
```

También puedes modificar:

```html
<h1>Para ti, aunque estemos lejos</h1>
```

y el mensaje final:

```html
<div id="finalMessage" class="final-message">...</div>
```

## Publicar gratis en Vercel
1. Crea una cuenta en Vercel.
2. Crea un repositorio en GitHub y sube estos archivos.
3. En Vercel selecciona **Add New > Project**.
4. Importa el repositorio.
5. Framework Preset: **Other**.
6. No necesitas Build Command.
7. Pulsa **Deploy**.

También puede publicarse directamente como sitio estático en Netlify o GitHub Pages.
